# Getting help

| You want to                                | Go to                                                      |
| ------------------------------------------ | ---------------------------------------------------------- |
| Talk to the team and other players         | [Discord](https://discord.gg/9jza5R62)                     |
| Know whether the servers are up            | [status.playreliquia.com](https://status.playreliquia.com) |
| Report a bug or ask for a feature          | An issue on the affected repository, using its template    |
| Report a security vulnerability            | [SECURITY.md](SECURITY.md), never a public issue           |
| Contribute or set up a development machine | [CONTRIBUTING.md](CONTRIBUTING.md)                         |
